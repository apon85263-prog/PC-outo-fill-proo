# PCC Passport Autofill Helper

A Chrome extension starter for local passport-text extraction and matching form fields.

## Important
- Passport data is not intentionally sent to a third-party server.
- The extension does not collect or store PCC passwords.
- Always verify every field before submitting an official application.
- This version handles some text-based PDFs. Scanned PDFs and JPG/PNG OCR are not bundled.

## Install
1. Extract the ZIP.
2. Open Chrome and go to `chrome://extensions`.
3. Turn on **Developer mode**.
4. Click **Load unpacked**.
5. Select this project folder.

## GitHub
Create a **Public** repository and upload the files. Never upload passports, passwords, cookies, API keys, or other personal information.
